## 7. 観察 / 読み解き (Insight)

> ここはデータ羅列ではなく、 集計から読み取れる **narrative** を書く。 単一データ点ではなく、 複数の事実を組み合わせて見える構造を整理する。

チェック観点 (該当するものを 1-2 段落ずつ):

- **時間軸の観察**: 「提案から契約まで N 年 N ヶ月」 / 「ブランク N 年」 / 「リーダー登用までの月数」 等
- **公開資料 vs 実態の乖離**: 職務経歴書 / resume PDF と GitHub 実態の差 (期間 / 案件数 / 役割)
- **収入規模 / 業界相場との関係**: 本業比 N% / 業界 median との比較 / self-anchor (本業時給) との整合
- **権限スコープの段階拡張**: リポ A → B → C → D と権限が広がった軌跡 (副業 / 業務委託で異例の領域に踏み込んだ等)
- **後年への波及**: 当時の構造 / 設計判断が、 後年の別案件 / 別組織でどう再利用 / 再構成されたか
- **構造的弱み / 未到達領域**: 領域内で本人が触れていない / 触れられない範囲 (上流フィードバック未提供 / 〇〇ロール未経験 等)
